# 「链千校」小程序拆解 —— 结构分析与可复用模型

> 分析对象：微信小程序「链千校」中的 **重庆工商职业学院 · 新生手册** 页面
> 抓取方式：读取本机已打开的小程序窗口（`WeChatAppEx.exe`，CEF 内核），逐屏截图 + 密码解锁阅读全文
> 结论：这是一套**多学校共用的「新生手册」模板产品**，不是某校自建页面

---

## 一、先看清它是什么

判断依据有三条硬证据：

1. 首页底部有独立入口 **「如何免费创建新学校？」** —— 说明学校是"入驻"进来的，模板统一、内容各校自填；
2. 正文页大面积有 **「荣~荣学长」斜排水印**，页脚是 `© 2026 荣荣学长 版权所有` —— 运营方是个人/团队，不是学校信息中心；
3. 点了 12 个「新生必看」里的某个入口，弹出的是**占位文案**：「学校管理员可在后台继续完善此处内容。」—— 说明这是模板默认页，等着学校管理员去填。

所以它的形态是：**一套模板 + 多租户内容后台**。这正是你要复刻的东西。

## 三、条目详情页：统一的「底部弹层 + 富文本」

12 个入口点开后，**全部是同一个范式**：

```
        ┌───────────────────────────────┐
        │ ▍报道流程                  ( × )│  ← 左侧蓝色竖条 + 关闭按钮
        ├───────────────────────────────┤
        │ 段落：来源声明 / 免责说明        │
        │                                │
        │ 🕐 报到时间与地点                │  ← 小标题（emoji + 文字）
        │ ┌────────┬──────────────────┐  │
        │ │ 项目    │ 详细信息          │  │  ← 表格：首列窄、加粗、浅蓝表头
        │ ├────────┼──────────────────┤  │
        │ │ 报到时间 │ 9月5日-6日 …      │  │
        │ └────────┴──────────────────┘  │
        │                                │
        │ ▎⚠ 橙左边框：切勿跑错！          │  ← 提示块：3 种配色
        │ ▎💡 蓝左边框：认准志愿者…        │
        │ ▎ 灰左边框：说明性内容           │
        │                                │
        │ 1 第一步 · 行李寄存              │  ← 步骤（可选）
        │   描述文字，支持**加粗**          │
        └───────────────────────────────┘
        背景：斜排浅色水印（学校名/运营方）
```

### 可复用的正文块（Block）类型

| 块 | 用途 | 关键参数 |
|---|---|---|
| `p` | 普通段落 | 支持 `**加粗**` 与换行 |
| `h2` | 小标题 | `icon`(emoji) + `text` |
| `table` | 表格 | `head[]` + `rows[][]`，首列自动加粗收窄 |
| `callout` | 提示块 | `tone` = `warn`(橙) / `tip`(蓝) / `info`(灰) |
| `list` | 要点列表 | `items[]`，圆点前置 |
| `steps` | 步骤流 | `items[{t,d}]`，序号圆标 |
| `img` | 图片 | `url` + `caption`，缺图显示占位斜纹 |
| `link` | 跳转 | `text` + `url` |

真实「报道流程」一文的块序列（我抓到的完整结构，已写进示例数据）：

> 段落 → 小标题 → 表格(3 行) → 段落 → 表格(2 行) → 警告块 → 小标题 → 表格(2 行) → 提示块 → 小标题 → 步骤(7 步) → 提示块 → 小标题 → 表格(5 行) → 小标题 → 表格(3 行) → 小标题 → 表格(5 行) → 说明块

## 四、它的变现/权限设计（最值得抄的一点）

正文滚到底部，会出现：

```
        🔒
   已开放 20% 正文
   后续内容已隐藏
设置密码是因为有些文件，不是本校的学生，是不能观看的。
请与管理员联系获取访问密码
   联系微信：xxxxxxxx
  ┌──────────────┐ ┌────────┐
  │ 输入访问密码   │ │ 继续查看 │
  └──────────────┘ └────────┘
```

三个要点：

1. **按比例截断**，不是按篇收费 —— 免费部分足够"尝到甜头"，又刚好卡在关键信息之前；
2. **密码分发** —— 天然形成私域流量（加微信才给密码）；
3. **服务端截断** —— 未解锁时，前端拿不到剩余正文（我的实现同样在服务端做遮蔽，不是前端隐藏）。

## 五、我的模板如何与它对应

| 原产品 | 模板中的字段 |
|---|---|
| 学校名 / 副标题 | `school.name` / `school.subtitle` |
| Banner 主副标题、背景 | `school.banner.{title,subtitle,image,tint}` |
| 主题配色 | `school.theme.{primary,bg}` |
| 正文水印 | `school.watermark` |
| 页脚版权 + 底部按钮 | `school.footer.{copyright,ctaText,ctaMode,ctaUrl}` |
| 「联系学长」名片（二维码 + 微信号） | `school.footer.contact.{name,wechatId,qr,tip}` |
| 「新生必看」等 3 个板块 | `school.sections[]`（`title` / `layout` / `visible` / `countText`） |
| 板块布局样式 | `section.layout` = `grid` \| `cards` \| `list` |
| 12 个图标入口 | `section.entries[]`（`title` / `icon` / `type`） |
| 卡片副标题 | `entry.subtitle` |
| 弹层正文 | `entry.blocks[]`（8 种块） |
| 密码墙 | `entry.lock.{enabled,freeRatio,password,contact}` |

## 六、做「另一所学校」时的取舍

| 项 | 原产品做法 | 建议 |
|---|---|---|
| 图标 | 彩色线性图标集 | 模板用 emoji（零依赖、后台直接改）；要更正式可换 iconfont，只需改 `renderSection` 一处 |
| 图片 | 校园实景图 | 模板支持 `banner.image` 外链；生产建议接对象存储上传 |
| 存储 | 未知（推断为云数据库） | 模板用 JSON 文件，单校几百条够用；多校并发请换 SQLite/PostgreSQL |
| 鉴权 | 小程序登录态 | 模板用 token（内存会话），生产需换 JWT + 密码哈希 |
| 密码墙 | 按 20% 截断 | 已实现，比例后台可调（5%–100%） |
| 多校 | 平台统一入口 | 模板用 `?s=slug` 区分，可绑不同域名做多租户 |
